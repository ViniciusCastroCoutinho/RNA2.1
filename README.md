# Perceptron de Rosenblatt
Neste projeto prático, o objetivo é implementar o algoritmo de treinamento mediante Aprendizado
Supervisionado do neurônio Perceptron de Rosenblatt aplicado em problemas de classificação, envolvendo três partes:
1. Resolvendo um problema linearmente separável
2. Experimentação com diversas configurações de redes neurais
3. Tentando resolver um problema não linearmente separável  

Para maiores detalhes, veja o pdf.
